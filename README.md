# OneKey builder history

A snapshot of OneKey's Hyperliquid builder activity, built from [Hydromancer Reservoir](https://hydromancer.xyz/hyperliquid-historical-data) data.

Live page: https://joshavenue.github.io/onekey-builder-history/

The page is one HTML file with its data and charts built in. It includes d3, which is under the ISC license (see `LICENSE-d3.txt`).
